# RUIZHE BEATS

Ruizhe 的四轨道节奏小游戏 / A four-lane rhythm game by Ruizhe.

## 开始游戏 / Play

下载 `index.html` 并用浏览器打开。 / Download `index.html` and open it in a browser.

- 电脑 / Desktop: D / F / J / K.
- 手机 / Mobile: 点击底部对应按钮 / Tap the matching bottom button.
- 音符抵达发光线时按下 / Hit when the note reaches the glowing line.
- 点击暂停按钮或按空格暂停与继续 / Use the pause button; Space pauses or resumes.

## 功能 / Features

- 中文与英文说明 / Chinese and English instructions.
- 30 秒曲目，120 BPM / 30-second track, 120 BPM.
- 轻松与挑战难度 / Easy and hard difficulty.
- 使用 Web Audio API 合成音乐 / Synthesized music using the Web Audio API.
- 浏览器本地最高分 / High scores stored locally in the browser.

无需安装依赖。音频在点击开始后启动。 / No dependencies to install. Audio starts after pressing Play.

分享按钮分享当前页面地址；公开可玩的链接需要另外配置网页托管。 / Sharing uses the current page URL; a public playable link requires web hosting.
