# Robot Arm Control and Path Planning

MATLAB and Simulink coursework/projects covering robot-arm control, robot motion simulation, and path-planning algorithms.

## Repository structure

- `robot-arm-control/flexible-robot-arm/` — flexible/elastic robot-arm models and controllers.
- `robot-arm-control/rigid-robot-arm/` — rigid robot-arm/control models.
- `robot-motion-simulation/` — basic robot/AGV motion and sensor simulation.
- `path-planning/` — path-planning code, grouped into RRT, Dijkstra, Voronoi/visibility, and common utilities.
- `docs/` — project reports and practice documentation.
- `media/` — demonstration media.
- `misc/unclassified/` — files whose role is not yet clear enough to classify safely.

## Tools

MATLAB and Simulink.

## Notes

Generated Simulink cache files and MATLAB autosave files are excluded from version control.
